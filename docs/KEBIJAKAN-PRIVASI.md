# Kebijakan Privasi HM Tracker

*Draf. Tinjau ulang dengan penasihat hukum sebelum dipublikasikan.*

## Data yang dikumpulkan

HM Tracker menyimpan data berikut di perangkat pengguna:

- **Nama pengguna dan jabatan/jenis alat**, diisi sendiri saat aplikasi dibuka.
- **Nama unit, lokasi kerja, dan batas servis** yang dimasukkan pengguna.
- **Angka HM meter dan waktu pencatatan**, termasuk nama operator jika diisi.
- **Foto meter**, yang sudah diberi watermark tanggal, jam, dan data unit.
- **Koordinat GPS** saat foto diambil, jika izin lokasi diberikan.

## Penggunaan data

Data dipakai hanya untuk menghitung pemakaian jam meter, menentukan status servis, mengirim notifikasi pengingat, dan membuat laporan atau cadangan yang diminta pengguna.

## Penyimpanan dan pembagian

- Semua data disimpan di perangkat. Aplikasi tidak mengirim data ke server milik pengembang.
- Data hanya dibagikan jika pengguna sendiri mengekspor CSV atau backup JSON, lalu membagikannya lewat aplikasi lain.

## Izin aplikasi

- **Kamera:** untuk preview dan mengambil foto meter.
- **Lokasi:** untuk mencatat koordinat GPS pada foto. Aplikasi tetap bisa dipakai tanpa izin ini.
- **Notifikasi:** untuk pengingat servis.

Pengguna dapat mencabut izin ini kapan saja lewat Pengaturan HP.

## Menghapus data

Pengguna dapat menghapus catatan satu per satu (tekan dan tahan), menghapus unit, atau menghapus aplikasi. Menghapus aplikasi juga menghapus data di perangkat. Simpan backup JSON sebelum menghapus.

## Kontak

Untuk pertanyaan tentang privasi, hubungi pengembang melalui halaman aplikasi di Play Store. *(Isi alamat email dukungan sebelum publikasi.)*
